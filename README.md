# TIK MASTER — Sistema Operativo y Encargado Virtual Empresarial

TIK MASTER es una aplicación privada para administrar, cotizar, asesorar y generar documentos de todo el negocio **TIK Smart Displays**.

Para consultar la documentación completa de arquitectura, guías de operación, despliegue en Hostinger y resultados de pruebas, consulte:
👉 **[TIK_MASTER_MANUAL.md](./TIK_MASTER_MANUAL.md)**

## Inicio Rápido

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar la aplicación:
   ```bash
   npm start
   ```

3. Acceder en el navegador:
   - Panel Principal TIK MASTER: `http://localhost:3000/tik`
   - Proyecto BRUK Hero preservado: `http://localhost:3000/bruk`

4. Ejecutar pruebas automatizadas:
   ```bash
   npm test
   ```
